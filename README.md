# Cloudy Clip Studio

Программа для Windows: берёт длинное видео и нарезает его на вертикальные ролики 9:16 для TikTok, Shorts и Reels. Всё работает локально, без платных облачных сервисов.

- Распознаёт русскую речь (faster-whisper, на видеокарте NVIDIA или процессоре).
- Находит самые интересные моменты локальной нейросетью (Ollama, по умолчанию qwen3:4b).
- Монтирует ролики: сокращает паузы, следит за говорящим, делает размытый фон, хук в начале, приближения, субтитры с подсветкой слов, рекламную вставку.
- Пишет название, описание и хэштеги, сохраняет субтитры `.srt`.
- Обновляется сама: при запуске предлагает новую версию, если она вышла.

История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Установка

1. **Python 3.11 (64-bit)** с [python.org](https://www.python.org/downloads/release/python-3119/). В установщике включите `Add python.exe to PATH`.
2. **FFmpeg**: в командной строке выполните `winget install Gyan.FFmpeg`, затем откройте командную строку заново.
3. **Ollama** (по желанию, для умного выбора моментов): [ollama.com/download/windows](https://ollama.com/download/windows), затем `setup_local_ai.bat`.
4. Скачайте `Cloudy_Clip_Studio_Source.zip` из раздела [Releases](../../releases/latest) и распакуйте в обычную папку, например `C:\CloudyClipStudio`. **Не** в `Program Files`.
5. Запустите `install.bat`. Он поставит библиотеки (и библиотеки видеокарты, если есть NVIDIA) и создаст ярлык **Cloudy Clip Studio** на рабочем столе.
6. Запускайте программу ярлыком.

Дальше обновления приходят сами: при запуске программа спросит «Доступна версия … — обновить?». Настройки, библиотеки и готовые ролики при обновлении сохраняются.

## Файлы

- `install.bat` — установка; `run.bat` — запуск с окном консоли (для диагностики).
- `enable_gpu.bat` — доустановить библиотеки NVIDIA для распознавания на видеокарте.
- `setup_local_ai.bat` — скачать модель для Ollama.
- Настройки: `%USERPROFILE%\.cloudy_clip_studio.json`. Журнал ошибок: `%LOCALAPPDATA%\CloudyClipStudio\app.log`.
- Ролики по умолчанию: `Видео\CloudyClipStudio\<имя исходника>`.

## Известные ограничения

- Баннер 1240×500 без растягивания занимает около 22.6% кадра, а не 25%.
- Слежение за говорящим — эвристика по движению губ; при быстрых склейках, профиле и нескольких говорящих одновременно возможны ошибки. При неуверенности программа показывает весь кадр.
- Сборка EXE (`build_windows.bat`) не включает библиотеки NVIDIA; основной способ установки — из исходников.

## Выпуск новой версии (для разработчика)

1. Поднять версию в `VERSION` и `APP_VERSION` в `cloudy_clip/updater.py`, дописать `CHANGELOG.md`.
2. `python tools/make_release.py` → `release/Cloudy_Clip_Studio_Source.zip`.
3. Создать GitHub Release с тегом `vX.Y.Z` (не pre-release) и приложить этот zip.
